Selected work

Project Aftershock

Automated ingestion and risk triage for regional seismic telemetry

Problem

Seismic readings arrive from the USGS API as deeply nested JSON. Anyone wanting to analyse a region had to unpick that structure by hand before any real work started.

Approach

Python ingestion scripts built on requests, json, csv and pathlib that pull the feed, flatten the payload, filter by region and write clean analytical tables to disk.

Result

Roughly 40% less manual preparation per run, and severity categorisation applied automatically so exploratory analysis can start from a tidy dataset.

  • Python
  • Pandas
  • Requests
  • JSON API
  • ETL

Sales performance dashboard

Relational modelling and an interactive Power BI report

Problem

Transactional sales records sat across several tables with no shared model, so regional questions took a new query every time someone asked one.

Approach

Multi-table SQL with joins and layered aggregations, reshaped into a normalised dimensional schema that Power BI could sit on top of cleanly.

Result

A dashboard with KPI cards, regional trend lines and drill-down filters, so the answers come from the report instead of from another ad-hoc query.

  • SQL
  • Power BI
  • Data modelling
  • DAX
  • Dimensional schema
